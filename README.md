# Horus Ambassadors Website

Official Website for Horus Ambassadors - Faculty of Engineering, Horus University-Egypt.

## Overview
Horus Ambassadors is the #1 student family at Horus University (HUE), bringing together engineering leadership, community charity, and scientific conferences. This website showcases our activities, leadership, events, and alumni.

## Tech Stack
- HTML5 / CSS3 / Vanilla JS
- **Vite** (Build Tool & Dev Server)
- Mobile-first responsive glassmorphic UI

## Getting Started Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Deployment to Vercel
This project is pre-configured to be deployed seamlessly on [Vercel](https://vercel.com).
Simply import this GitHub repository into Vercel and it will automatically detect the Vite framework and deploy the `dist` folder.
